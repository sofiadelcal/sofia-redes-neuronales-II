# Redes Neuronales II

Este repositorio contiene el desarrollo de la actividad **R1-A2-S4** de la asignatura *Deep Learning - Conceptos*.

El notebook presenta, de manera progresiva, los siguientes ejercicios:

- Perceptrón programado desde cero.
- Neurona sigmoide para clasificación binaria.
- Red multicapa con backpropagation manual en NumPy.
- Clasificación de dígitos MNIST con TensorFlow y Keras.
- Implementación equivalente con PyTorch.

## Ejecución

Abre el archivo `Sofía_Redes_Neuronales_II_Colab_Explicado.ipynb` en Google Colab y ejecuta las celdas en orden.
